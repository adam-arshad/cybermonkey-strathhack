# CyberMonkey

**A cyber security awareness tower defence game, built in 24 hours at StrathHack 2026 for the ScottishPower Cyber Awareness Challenge.**

## Tech stack

- **TypeScript**
- **Phaser 4** for rendering and animation
- **Vite** for development and builds
- **Node.js test runner** for automated tests

## About 

Players buy security controls on a £3m budget, match them to attacks across four phases, answer cyber security questions, then defend their network in tower defence waves.


-  Challenge brief, starter code, questions and artwork provided by ScottishPower for StrathHack 2026.
- Built by Jason, Uzair Ansar, Zubair Mohammed, Moadd-A and Adam Arshad.
